# Copilot for Flint

Native AI assistant with local LLM integration, multimodal reasoning, automated summarization, and context-aware chat.

## 1. Installation
---

Install directly within Flint from the **Community Extensions Marketplace** or place into your Hearth's `.flint/extensions/flint-copilot/` folder.

## 2. Building Locally
---

```bash
npm install
npm run build
```
